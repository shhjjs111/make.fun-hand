Methodology

How implied value is computed

One equation for the value if a token launches and one for the odds it does, fitted on the snapshot's own token-bearing protocols. No protocol is named: every row is scored by the same function, and the page recomputes each row's value from its inputs and checks it against board.json.

main.ts fits the model → data.js carries the coefficients and rows → the page recomputes every row → board.json is the value the page checks against.
